# Code of conduct

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1, reduced
to what applies to a repository of documents and one test suite.

## The short version

Argue with the work, not the person. Review here is mostly "this sentence will not survive a session
that has not read it", and that is a comment on the sentence.

## Expected

- **Cite the file and the number.** "This claim is falsified by `npm run spec`" is a review; "this is
  wrong" is not.
- **Say what lost.** A decision without its rejected alternative is a preference, and this repository
  refuses preferences.
- **Assume the reader is the next session**, which has no memory of this one.

## Not acceptable

- Harassment, insults, or personal attacks in any repository space — issues, pull requests, commit
  messages, discussions.
- Sexualised language or imagery, and unwelcome attention of any kind.
- Publishing someone's private information without their explicit permission.
- Sustained disruption: reopening a settled decision without new evidence, or arguing in bad faith
  about what a file says when the file can be read.

## Scope

Applies to issues, pull requests, commit messages and any space where someone is representing this
project.

## Enforcement

Report to <hi@benxgao.com>. Reports are read privately. Responses, in order of what the behaviour
requires: a private word, a comment removed, a contribution closed, a block. There is no committee and
no appeals process — this is a one-person project, and the maintainer's decision is the decision.
