# DISCUSSION

`DISCUSSION` represents unresolved project knowledge.

## Create

Create a discussion when:

* required information is missing
* multiple valid interpretations exist
* user clarification is required
* an unresolved decision affects implementation
* a potential requirement needs confirmation

## Rule

Do not create a discussion for uncertainty that is:

* non-critical
* safely reversible
* irrelevant to future work

## Resolve Discussions

When resolve discussions:

- Record the durable outcome briefly in `SPEC` or `ADR` when appropriate, and avoid duplicating the same information.
- Delete the original discussion entry only after the ADR/SPEC is successfully created.
- Deleting a resolved entry is the one sanctioned removal; it is not a rewrite of history.
- The ID is not reused, including the ID just deleted.
- Leave unanswered discussions unchanged.
